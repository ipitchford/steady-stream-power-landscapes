# Richter comparison: consequence for originality

Gerard R. Richter, “An inverse problem for the steady state diffusion equation,” SIAM Journal on Applied Mathematics 41(2), 210–221 (1981), DOI [10.1137/0141016](https://doi.org/10.1137/0141016). The user supplied the complete 12-page PDF; text and selected rendered pages were inspected. The file is not redistributed.

Richter writes L(a;u)=grad u dot grad a+(Delta u)a=div(a grad u). Substituting u=-z, a=b, f=rho gives exactly the manuscript's prescribed-elevation drainage equation.

- Printed p. 213 specifies bounded characteristic solutions.
- Lemma 3, p. 215, supplies the characteristic reconstruction through a region of positive Laplacian, including the critical-point ratio.
- Theorem 1, pp. 216–217, combines nonvanishing-gradient and positive-Laplacian regions, with inflow data. Under the manuscript's compactness and inward uphill-flow conditions, positivity of -Delta z on the critical set supplies such a cover. With u=-z, the boundary is outflow, so the inflow set is empty.
- Theorem 2, p. 219, explicitly addresses the positive-source, zero-Dirichlet inverse setting without extra Cauchy data.

Therefore the existence/uniqueness sufficiency principle for the linear multiplier is not new. Version 1.2 withdraws that implication in the introduction, comparison table, theorem description and claim ledger. The explicit Hölder estimate and global distributional argument remain useful ingredients, but their presentation is not an independently established originality claim.

Richter prescribes u. He does not establish the coupled stream-power nonlinear fixed point or the new constant-forcing local contraction theorem. This distinction supports a candidate contribution; it does not by itself establish priority over all later literature.
